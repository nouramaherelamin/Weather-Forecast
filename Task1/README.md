# Weather Time-Series EDA — Banha, Egypt

## Overview
Exploratory time-series analysis of daily weather in Banha, Qalyubia, Egypt, from 1 January through 31 December 2025. The project uses the NASA POWER Daily Point API for mean, maximum and minimum temperature, corrected precipitation, relative humidity, and wind speed. NASA POWER is free, does not require an API key, and offers long historical coverage.

## Run in Jupyter Notebook
1. Open this folder as your working directory in Jupyter.
2. Install dependencies: `pip install -r requirements.txt`.
3. Open `Weather_Time_Series_EDA.ipynb` and choose **Kernel → Restart & Run All**.
4. The notebook reuses `outputs/raw_weather_data.json` by default so it can run without internet access. To refresh from NASA POWER, set `REFRESH_API = True` in the API cell and run the notebook with internet access.
5. Figures are saved in `figures/`; tables and the summary report are saved in `outputs/`.

## Analyses
Data-quality checks; descriptive statistics and distributions; daily time-series plots; rolling statistics; monthly temperature boxplots; classical and robust STL decomposition; ACF/PACF; ADF and KPSS tests before and after first differencing; correlation heatmap and lagged correlations; global IQR and rolling z-score outlier review; diurnal temperature range; cumulative precipitation; monthly wet days; and log1p precipitation distribution. An Open-Meteo comparison is optional and is not treated as ground truth.

## Limitations
NASA POWER provides gridded/reanalysis-based estimates rather than direct measurements at a local weather station. Spatial resolution and precipitation uncertainty matter, especially in a relatively dry region. A single year is insufficient to establish a reliable annual seasonal component.
